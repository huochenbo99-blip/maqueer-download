麻雀儿隐私政策

更新日期：2026年11月23日　生效日期：2026年11月23日

麻雀儿是个人开发的非官方校园工具，与学校、教务系统及校园卡平台无隶属关系。

一、功能与本地数据

功能：教务课表、成绩、考试；校园卡余额、账单、付款码和充值；快递单号记录；上课提醒；桌面小插件；检查更新；论坛和教师评分。

教务 Cookie、学号、姓名、班级、课表、成绩、考试；校园卡号、余额、账单；快递单号和取件码；提醒开关和课表数据只保存在手机本地。校园卡密码保存在 Android Keystore。充值只把金额、卡号和登录令牌提交给学校官方收银台，本应用不保存银行卡号、支付密码或支付账户信息。

二、上传与第三方

论坛和教师评分内容、随机匿名昵称、随机安装标识、发布时间和举报原因会发送到新加坡的 Supabase 并保存，构成个人信息出境。检查更新只向 GitHub 请求公开版本信息，不包含个人信息。除学校系统、Supabase 和 GitHub 外，开发者不运营其他服务器。

三、权限

网络访问：访问学校系统、Supabase 和 GitHub。通知（可选）：仅在你开启上课提醒时申请。开机自启和精确闹钟（可选）：仅用于重启后恢复并准时发出你已开启的上课提醒。不申请短信、存储、位置、相机、麦克风、通讯录、电话、设备信息等权限。

四、我们不收集

手机号、短信内容、通讯录、位置、相册、相机、麦克风、IMEI、MAC、Android ID、广告标识、应用列表、剪贴板后台内容。本应用不含广告、推送、统计、崩溃上报等第三方 SDK。

五、存储与删除

本地信息保存在手机中，直至你主动删除或卸载。你可以在「我的」退出教务、解绑校园卡，或在系统设置中清除应用数据。论坛帖子保留 7 天；教师评分和评论保留至你删除或按规则处理。

六、安全与联系

本应用使用 HTTPS 与学校系统、GitHub 和 Supabase 通信。请妥善保管学号、密码和手机，不要在论坛或评分中发布身份证号、手机号、住址等敏感信息。
